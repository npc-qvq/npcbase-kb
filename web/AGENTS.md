# 前端代码规则

## 注释要求

- 前端代码优先面向具有基础 HTML 和 CSS 知识的学习者编写。
- `main.ts`、组件文件和工具文件中的每个状态变量、接口数据类型、方法和关键计算属性都必须添加中文注释。
- 方法注释应说明用途；有参数时使用 `@param` 说明参数含义；有返回值时使用 `@returns` 说明返回内容。
- `fetch` 请求、登录状态处理、文件上传、删除确认和 AI 接口调用等关键逻辑前，必须说明业务目的。
- CSS 必须按页面区域使用中文注释分段；复杂布局、响应式断点和关键视觉变量必须说明用途。
- 注释应解释“为什么这样做”和“数据从哪里来”，避免只重复变量或方法名称。

## 修改要求

- 修改任意前端 TypeScript、Vue 或 CSS 文件后，必须完整检查该文件中新增或已有的变量、方法与关键样式是否缺少上述注释。
- 不得因为补充注释改变现有接口路径、请求参数、响应字段或业务功能。
