# 第一阶段完成状态

第一阶段目标是搭建可用、可验证的个人知识库 RAG 基础链路；该目标已完成。

## 已完成

- 文档上传、原文件保存、后台解析和文本切片。
- 文档、切片、索引任务持久化至 MySQL。
- 使用 SiliconFlow `BAAI/bge-m3` 生成 Embedding，并写入 Qdrant collection。
- 使用 BGE Reranker 对向量召回结果二次排序。
- 默认本地资料检索模式，不调用 DeepSeek。
- 在会话中输入 `小c启动` 后执行“向量检索 + DeepSeek 归纳”的增强问答。
- 在会话中输入 `小c关闭` 后恢复本地资料检索模式。
- 历史会话、消息、引用资料持久化；支持会话删除和资料删除。
- 资料删除时同步清理 MySQL 切片与任务、文件目录及 Qdrant Point。
- 前端已完成三栏知识库工作台、资料上传、会话历史和自定义删除确认弹窗。

## 本阶段不包含

- 登录、JWT、用户管理和细粒度权限控制。
- 多租户、多知识库隔离和文档权限过滤。
- 流式输出、联网搜索、工具调用。
- LangChain4j。当前项目已直接完成模型与 Qdrant 编排，引入框架不是第一阶段的必要条件。

## 推荐的下一阶段

1. 改进文档清洗、标题识别和按段落语义切片。
2. 加入关键词与向量的混合检索，并评估召回质量。
3. 优化 DeepSeek 提示词，要求答案先给结论、仅依据引用资料作答。
4. 对 IP、接口地址、端口、账号等固定字段建立本地规则提取。
5. 按需要加入流式响应、文档分类/标签和多知识库筛选。
6. 确认部署边界后，再设计登录、权限和审计能力。

完整架构和启动方法请查看 [README](../README.md) 与 [项目流程说明](项目流程说明.md)。
